What is this?

A live demo of an e-commerce backend written in Java 21 / Spring Boot 3.5 as a modular monolith (Spring Modulith): identity, catalog, ordering, payment and notification modules with verified boundaries, communicating through transactional domain events.

Checkout reserves stock atomically, the order starts PENDING, the payment module charges it asynchronously and the order becomes CONFIRMED (orders above ₹50,000 are declined by the simulated card → CANCELLED, stock returned).

The same system also exists as 8 Spring Cloud microservices (gateway, Keycloak, RabbitMQ saga with outbox, Eureka, Config Server, Zipkin/Grafana) in the same repository.
